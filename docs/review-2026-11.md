## Helhetsbedömning

Designen är sammanhängande och ovanligt väl uppmätt för ett projekt som aldrig har körts på riktig hårdvara. Länklagret (RS16×2, whitening, viktgräns, strukturkontroller) är sunt; Reed–Solomon-koden klarade 270 600 testfall utan fel [M], och koden stämmer med specen överallt där granskarna kontrollerade. Det som saknas är fyra saker: (1) fälttest – allt är simulator och in-process; (2) ett fåtal riktiga buggar och scenfarliga standardbeteenden; (3) några protokollvinster som är stora och billiga; (4) versions-, struktur- och produkthygien innan repot kan kallas open source-redo.

## F. Inbakning i instrumentets ljud (branch `claude/tender-johnson-pfysx4`)

**Prototypen:** fyra relativa kommandon (bank±, program±) som 4×4 ms tonsignaturer på 20,0–21,5 kHz; RX högpass 19,5 kHz → Goertzel → renhet efter filter. Ingen CRC, ingen nyttolast, inte AML. Återskapat: alla tester passerar och rapporten regenereras exakt [M]. Grundvalen är rätt: en ton i taget, renhet mätt *efter* filter, nivåoberoende, ortogonala binar.

**Håller inte / inte testat [M om inget annat anges]:**
1. Den syntetiska "bandet" är orealistiskt mörkt över 19,5 kHz (−116 dBFS); verklig pickup ≈ −30 dB vid 20 kHz, pedalbord −85…−95 dBFS brus + spurrar. Raderna "−50/−60 dB under musiken" är artefakter; vid CLI-standard −30 dBFS fungerar det ändå 100 %.
2. **En spur på −40 dBFS i en tonslot** sänker leveransen till 83 % (kommandon −30 dBFS) och 0 % vid −34. Ingen har mätt 19,5–24 kHz-golvet på riktiga pedalbord/PSU:er – **första fältmätningen**.
3. 44,1 kHz: 66 % genom ett skarpt 44,1-hopp – oanvändbart. Codec/trådlöst (19 kHz LP): 5 %. **Anta att ingen trådlös länk passerar 20–21,5 kHz.**
4. **IMD genom analog dist efter lådan:** vid −30 dBFS hamnar resterna bara 22–32 dB under den distade gitarren – ett 16 ms blipp hörs. Analogt stripfilter kan inte lösa det (4:e ordningens 18 kHz: −5 dB vid 20 kHz, redan −0,9 dB vid 15 kHz [E]). Alltså: tonerna får aldrig nå ett olinjärt steg, eller lådan måste ha en digital väg som tar bort dem.
5. Ordförrådet kan inte växa: max 7 kommandon med 7 toner [E]. Riktiga behov (direkt preset, stomp på/av, tap tempo, tuner, snapshots, expression) kräver nyttolast + check = AML:s länklager. Relativa kommandon driver ur synk vid ett missat/dubblerat kommando.
6. Noise gates, tuner-mute och mute-switchar mellan inbakning och låda dödar kommandon som skickas när gitarren är tyst – exakt när man byter preset.
7. Latens 16 ms + omvandlare + I2S + MIDI + målenhetens presetbyte (10–100 ms) ≈ 18–20 ms före bytet startar [E].
8. Branchen ligger 11 commits efter main; konflikter i fyra filer (CHANGELOG, README, cli/main.rs, core/lib.rs), alla mekaniska. Förslagsdokumentet påstår mätningar (44,1, omvandlare, IMD) som granskarens kanalmodeller delvis motsäger – uppdatera innan någon testar på rigg.

**Alternativen i korthet:** (a) LSB/residue i digitalt programljud: 1,8 ms, −83 dBFS brus, men **bara bit-exakt** (0,0005 dB gain-tolerans) [M] – relevant för digitala keyboards/uppspelning på ren Dante-route. (b) **Bandskiftad AML** 19–20,5 kHz över passiv gitarr: Robust 100 % vid −30/−40 dBFS genom rena/skarpa/långsamma omvandlare, 44,1-hopp och 19 kHz codec-LP tack vare raderingstoleransen; Fast 19–22 kHz 54 ms, bara 48 kHz [M]. 20–21,5 kHz vid ≤ −30 dB är ohörbart för praktiskt taget alla vuxna (52 % av under-30 svarar alls vid 20 kHz [R]); 17–19 kHz hörs av tonåringar. (c) Perceptuell vattenmärkning: 0,2–20 bit/s, sekunder i latens, patentminfält – nej. (f) **Stereopar** med ljud på ena kanalen och Cricket på den andra: slår varje inbakning på alla axlar utom "en monokabel".

**Rekommendation:** bygg en **HF-profilfamilj i AML** (`hf_fast` 19–22 kHz 3 ms ≈54 ms/paket; `hf_robust` 19–20,5 kHz ≈169 ms) med band-pass-front-end och renhet efter filter, oförändrat länklager, schemaläggare och fail-safe – **inte** signaturschemat. Behöver stompar <54 ms: kort CRC-skyddad paket-phy i samma band (≈30–45 ms) snarare än fler signaturer. Behåll `pedal` som experiment utanför AML; skicka aldrig relativa kommandon utan kvittens.

**Lådan:** analog hårdkopplad genomgång + högimpedant tap (≥1 MΩ ‖ ≤10 pF): 0 ms, inget tillagt brus, ~1 €; valfri andra utgång "till FOH/DI" med digital strip (−56 dB) för de fall tonerna inte får fortsätta. Sändare: via 1 MΩ från lågimpedant oscillator på instrumentet (ingen klangändring), trivialt efter buffert/pedalbord, trivialt digitalt i keyboard. Placering: lådan först på pedalbordet = nästan ideal kanal; vid FOH efter DI/lång kabel/trådlöst överlever bara 48 kHz PCM eller koppar.

**Acceptanskriterier "spelbart":** 0 ms (analog) eller ≤1,5 ms (digital) tillagd latens; ±0,1 dB 20 Hz–20 kHz vid 1 MΩ; THD+N ≤0,003 %; brus ≤ −105 dBu; 100 % av 1 000 kommandon genom 6 m kabel + tre buffrade pedaler; 0 falska på 24 h; ohörbart i AB-test genom fullregister-PA vid 100 dB SPL med toner ≤ −30 dB; IMD-blipp genom high-gain ≤ −45 dB eller strippat.

**IP:** LISNR (18,7–19,2 kHz, 131 patent), Chirp→Sonos, CUE Audio, Intrasonics; Nielsen/Verance för maskeringsbaserat. Ingen hittad produkt gömmer MIDI/tidkod ultrasoniskt i instrument- eller uppspelningssignal. Gör en FTO-sökning (CPC G10H 1/0058, G10H 3/18, H04B 11/00, H04H 20/31) före lansering.

**Insats [E]:** HF-profil + front-end + tester 1–2 v; ESP32-S3/RP2350-firmware med analogt tap 2–3 v; bänkrigg + hörbarhetstest 1–2 v; LSB/residue-phy ~1 v ovanpå `digital.rs`.

## G. Det som är bra och inte bör röras
