# UX / field review (agent report, 2026-11-08)

## HIGH
1. Unknown profile silently becomes robust (config.rs from_name `_ => robust()`, CLI free-text --profile). Fix: Result + clap value list.
2. Encoder plays C-major test scale whenever no MIDI In set (encoder.rs use_sim = simulate || MidiIn::None; GUI main.ts same, MIDI In defaults None). Fresh install → notes on stage synth. Make opt-in.
3. Only device channel 1 decoded; TX writes all output channels; UI silent (audio.rs). Add in/out channel select, show "listening on ch 1".
4. Stopping decoder (GUI Stop / Ctrl-C) sends no fail-safe burst (decoder.rs run). Add burst on stop + decoder-side Panic.
5. No binaries; versions contradict: crates 0.1.0, tauri.conf/package.json 1.0.0, index.html "v1.0", CHANGELOG 1.1.0 unreleased, no tags. CI has no release job, no signing/notarisation, no NSMicrophoneUsageDescription (macOS TCC kills bundled app opening input). README quick start needs Rust+ALSA+Node.
6. Input meter red at nominal level (main.ts percent = rms*400). Use dBFS scale −60…0 with −30…0 good window.
7. CLI prints no link status (print_events drops Stats/Level). Add periodic status line + --json NDJSON.

## MEDIUM
8. Alarm UX: single banner, last wins, only audio_input_stalled clears; link_dead stays red after recovery. Need alarm list, AlarmCleared{LinkDead}, acknowledge.
9. "Search" explains nothing (wrong profile / EQ / −35 dB / no cable all look same; CRC pass 100% before any packet). Expose level dBFS, preambles found vs CRC fails, fec_corrected (ModemStats has it, LinkStats drops it). Later: profile-ID nibble in heartbeat.
10. MSC interop: lists capped 15, cue paths & 2-decimal cues rejected (msc.rs); grandMA executors >15 and page-as-path; Eos point cues 10.25 and SET rejected; alarm wording engineering-ish and overwritten; source device ID discarded (can't address several MSC devices).
11. GUI dropdown latencies mislead (index.html: Robust ~169, Robust repeat ~130, Fast ~54 = first-copy airtimes). Show measured mean/p95 or label.
12. "Self-Test" is in-process benchmark of fast+robust (lib.rs run_self_test). Rename; add real link test through devices for any profile.
13. No autostart, presets, export/import; CLI no config file.
14. Stale docs: cricket_gui/README.md (Robust ~136 ms, MSC-lite), release-checklist.md (v1.0, Fast ≤60), CHANGELOG says aml_cli/aml_core, no docs index; README 2400 words, quick start 2/3 down.
15. TX drops log-only; expose counters.
16. CLI ergonomics: three "tests"; global flags clutter list-devices; --profile help 120 words; -m/-a differ between encode/decode; exit code always 1; pathcheck Marginal exits 0; list-devices aborts when ALSA seq missing.
17. Platform notes buried (WASAPI shared breaks digital; ALSA hw: vs default); GUI never warns Windows user picking digital/ltc14400.

## LOW
18. Default devices = built-in speakers/mic → −2 dBFS chirps from laptop. Warn; TX level choice.
19. Confidence bar dB×10, per-phy meaning, no good mark.
20. Wording inconsistencies; alarm kinds undocumented.
21. No hardware-box FAQ.

## Naming/tiering proposal (keep old as aliases)
Analog Safe (robust, default) / Analog Safe + Repeat (robust_repeat) / Analog Fast (fast) / Clean Line (ltc_fec) / Clean Line Fast (ltc9600_fec) / Digital Line (ltc14400_fec) / Digital Bit-Exact (digital). Uncoded variants → "Advanced: no error correction" toggle. 3-question wizard.

## GUI parity gaps
digital/+digital, uncoded ltc*, pathcheck, --buffer-frames, --sample-format, link_dead_ms, loopback chords/throughput, WAV in/out. CLI lacks Panic, remembered devices, meters.

## Show-ready MVP checklist
profile validation + tiered names; channel select; test scale opt-in + Identify button; traffic light LINK OK/NO SIGNAL/SIGNAL NO LOCK/DEAD + seconds since heartbeat; dBFS level + fec-corrected/CRC-fail per min; alarm list/auto-clear/ack; decoder Panic; fail-safe on Stop; MIDI monitor; TX dropped/rejected counters; autostart + presets + JSON export/import; real link test + pathcheck in GUI; signed installers + release workflow + one version; docs: quick start first, routing guide, troubleshooting, MSC console presets, hw FAQ, simulator banner.
